# Go tsnet ingress

This is the Go side of the isolated bridge prototype. `Protect` resolves each request/upgrade using the tsnet node's LocalAPI WhoIs. `UnixForwarder` strips untrusted identity headers, signs a fresh request-bound Ed25519 assertion, forwards only to the protected Node Unix socket, and validates Linux `SO_PEERCRED` for each socket connection. HTTPS listens only on `ts.Listen("tcp", ":443")`; exact `ts.CertDomains()` names use Tailscale LocalAPI certificates, while a strict one-label SNI match under `PREVIEW_DOMAIN` uses the owner-provisioned wildcard certificate. HTTP Host must match TLS SNI. Owner certificate/key files are protected non-symlink files; the chain must be current, match its key, cover the configured wildcard and verify against system public roots. SIGHUP reload clears the active preview certificate before validation, so invalid material fails closed. Key access uses Linux `O_NOFOLLOW` plus `fstat`; unsafe paths, UID mismatch, and unsupported OS fail closed.

See [`../README.md`](../README.md) for the security boundary and strict disposable Linux ARM64 cross-process test instructions. The Go toolchain was unavailable in the authoring environment; no deployment or production security claim is made.
